## 二、WireGuard 服务端

配置文件：`C:\Users\PCserver\wg0.conf`

```ini
[Interface]
PrivateKey = <SERVER_PRIVATE_KEY>
Address = 198.18.0.1/24
ListenPort = 51820

[Peer]
PublicKey = <CLIENT_PUBLIC_KEY>
AllowedIPs = 198.18.0.2/32
```

注册成服务（开机自启）：

```powershell
& "C:\Program Files\WireGuard\wireguard.exe" /installtunnelservice C:\Users\PCserver\wg0.conf
# 卸载
& "C:\Program Files\WireGuard\wireguard.exe" /uninstalltunnelservice wg0
```

服务注册表实测值：

```

Start      = 2   (Automatic)
ObjectName = LocalSystem
```

## 四、防火墙

```powershell

  -LocalPort 51820 -Action Allow
```

## 五、远程操作约定（必须遵守）

远端只有 **Windows PowerShell 5.1**，没有 pwsh 7。

```powershell
# 唯一可靠方式：EncodedCommand（避免引号被 bash/ssh 二次解释）
function RemotePS([string]$script){
  $enc = [Convert]::ToBase64String([Text.Encoding]::Unicode.GetBytes($script))
  ssh -o ConnectTimeout=8 pcs "powershell -NoProfile -EncodedCommand $enc"
}

RemotePS 'Get-Service sshd | Format-Table Name,Status,StartType -AutoSize'
```

不要这样写（引号会被吃掉，报 `TerminatorExpectedAtEndOfString`）：
```powershell
ssh pcs 'powershell -NoProfile -Command "Get-NetIPAddress | Where-Object { $_.X -like \"*wg0*\" }"'
```
