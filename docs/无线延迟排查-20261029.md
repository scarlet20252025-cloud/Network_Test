## 一、最终确认的事实（这些是可靠的）

同一台 AP（`10:2f:6e:84:73:8f`）、同一信道（40）、同一频段（5GHz 5200MHz）、
同一时刻、同样的测试方法（`ping -i 0.2`，50 包）：

| 设备 | 结果 |
|---|---|
| 手机（vivo V1824A） | `min 1.87 / avg 5.21 / max 14.42 / mdev 2.67` |
| 本机（Realtek 8852BE） | `p50 67 / p90 81 / max 89 / 尖峰 38/50 (76%)` |

**相差 13 倍，且本机 76% 的包都在 50ms 以上。**

## 三、驱动 INF 里读到的默认值（重要）

从 `backup/drivers/netrtwlane601.inf` 反查出来的，**这些不是谁改坏的，是
Realtek 驱动自己调的**：

```
HKR,,ProtectionMode,0,"4"      保护机制：默认启用
HKR,,protect_by_env,0,"1"      按环境启停
HKR,,CoreAMSDU,0,"1"           A-MSDU 聚合：默认开
HKR,,AMfactor,0,"253"          聚合因子
HKR,,ForcePCIeRate,0,"1"       "Force to Gen 1" —— PCIe 强制降到第一代
```

这解释了一件事：**我之前改的那些注册表项，本质上是在和一个"经过 Realtek
调优的默认配置"对抗**，而改完测出来的数字又都在自然波动范围内，无法判断真假。

## 四、方法论上的教训（最值钱的部分）

### 1. 单次 15-20 个包的样本在 wifi 环境下完全不可信

同一台机器、同一个网关，间隔十几分钟的两次测量：

```
21:30   p50=15  max=82   尖峰 15%
22:00   p50=56  max=86   尖峰 67%
22:20   p50=52  max=131
22:26   p50=52  max=155  尖峰 60%
```

**p50 从 15ms 变到 56ms，中间没改任何东西。**

连手机自己在同一分钟内也会「抖一阵稳一阵」（实测 max 从 61ms 掉到 8.7ms）。
用这种样本做 A/B 对比，每次结论都不一样 —— 这正是我前 30 轮反复改口的原因。

**正确做法**：≥100 包、多轮交替、看 p50 和尖峰比例，**不要看单次 max**。

### 2. 报告信息可能指向完全错误的位置

`Ferry-Setup-1.0.47.exe` 从 `E:\肥鱼不乐园\...\dist\` 双击安装，报：

```
安装程序无法创建目录 C:\Users\...\Temp\is-XXXX.tmp，错误 5 拒绝访问
```

报错**指着 %TEMP%**，我据此查了 ACL、Smart App Control、AppLocker、火绒、
Zone.Identifier —— 全是干净的。真实原因是**源路径含中文**：Inno 的 SetupLdr
从非 %TEMP% 路径启动时要先把自己复制到 %TEMP% 再带 `/SL5` 重跑，这一步
在中文源路径下失败。

**识别方法**：`/LOG=` 指定的日志**一行都没生成**，说明它死在 Inno 的日志机制
启动之前 —— 那时就该怀疑「不是 Temp 写不进去，而是它压根没走到那一步」。

### 3. 「性能问题」不要从最可疑的地方开始猜

`RefreshUi()` 每秒跑一次，里面有 40 处 `.Text =`、37 处 `.Foreground =`、
14 处 `.Content/.Background/.Visibility` —— **全部无条件赋值**，而 WPF 的
这些都是依赖属性，赋内容相同的值也会走完整的 measure/arrange/重绘。

第一轮我只改了 `TextBlock`（还顺手把 `Palette` 的 Brush 改成 `static readonly`），
CPU 从 82% 只降到 **78%**，我以为差不多了。直到把**所有**依赖属性赋值系统地
扫一遍、加上 `SetContent/SetBg/SetVis`，才降到 **7.2%**。

**教训**：定位性能问题要枚举该函数里**所有**同类操作，不要只改想到的那一类。

## 五、还没做的验证（下一步）

1. **USB 无线网卡对照**（最快给出结论）
   - 插 USB 网卡 → 禁用板载 WLAN → 测延迟
   - 正常 → 确认是板载 8852BE 的问题 → 换 Intel AX210（约 60 元，M.2 通用）
   - 一样慢 → 系统层问题，继续查

2. **USB 网络共享对照**
   - 手机 USB 共享网络给电脑，测到网关的延迟
   - 可以区分「无线链路」和「整个网络栈」

3. **用另一台电脑连同一 AP**（如果手边有）

## 六、还原清单

如果之前做过实验性改动，按这个还原（`IpsEn=0` 可以保留，无害）：

```powershell
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Class\{4d36e972-e325-11ce-bfc1-08002be10318}\0007" /v LpsEn /t REG_DWORD /d 2 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Class\{4d36e972-e325-11ce-bfc1-08002be10318}\0007" /v CoreAMSDU /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile" /v NetworkThrottlingIndex /t REG_DWORD /d 10 /f
powercfg /setacvalueindex SCHEME_CURRENT SUB_PCIEXPRESS ASPM 2
powercfg /setdcvalueindex SCHEME_CURRENT SUB_PCIEXPRESS ASPM 2
powercfg /setactive SCHEME_CURRENT
Restart-NetAdapter -Name WLAN -Confirm:$false
```
