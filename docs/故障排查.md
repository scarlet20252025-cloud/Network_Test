## A. 借网不通

### A1. 先看客户端界面的三个状态

| 界面显示 | 含义 | 下一步 |
|---|---|---|
| 「隧道 未连接」+「本地代理 未运行」 | 根本没起来 | A2 |
| 「本地代理 运行中」但「系统代理 关」 | 代理起了，没接管系统代理 | A4 |
| 「借网异常」 | 系统代理指着渡口，但本地端口没响应 | 点「停止并恢复直连」再「开始借网」 |
| 「直连」 | 本来就没借网 | 点「开始借网」 |

### A2. 本地代理端口有没有人监听

```powershell
netstat -ano | findstr :10801        # 应该有 LISTENING
curl.exe --noproxy '*' -x http://127.0.0.1:10801 --max-time 10 https://myip.ipip.net
```

- 端口在、curl 有输出 → 借网链路通，问题在「谁没走代理」（看 A4）
- 端口在、curl 超时 → 出口方向的问题，看 A3
- 端口不在 → 客户端没起代理，看日志：`%LOCALAPPDATA%\Ferry\assistant.log`

### A3. 出口机通不通

```powershell
# 出口机的服务端口
Test-NetConnection 10.13.24.1 -Port 1080 -InformationLevel Quiet

# 直接从客户端机器测出口机的 SOCKS
curl.exe --noproxy '*' -x socks5h://10.13.24.1:1080 --max-time 10 https://myip.ipip.net
```

> `socks5h` 的 **h** 很关键：让代理自己解析域名。不带 h 是本机解析，
> 被禁网的机器 DNS 可能根本解析不出来，测出来是假失败。

不通的话去出口机上查：

```powershell
# 服务在不在
netstat -ano | findstr :1080
# 计划任务状态
schtasks /Query /TN FerryPortal /FO LIST
# 看日志
Get-Content C:\ferry-portal\*.log -Tail 40
```

### A4. 能通但网页打不开（代理没生效）

```powershell
# 当前系统代理
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings' |
  Select-Object ProxyEnable, ProxyServer
```

- `ProxyEnable = 0` → 系统代理没开。客户端里点一次「停止并恢复直连」再「开始借网」
- `ProxyServer` 不是 `127.0.0.1:10801` → 被别的软件（Clash 等）改回去了。
  客户端每秒会自检并纠正，若反复被改，先退出那个软件
- 有些程序**不认系统代理**（多数游戏、部分 Electron 应用）→ 必须开全局模式（D）

## B. 安装与启动

### B1. 双击安装包没反应

先看有没有残留进程占着文件：

```powershell
Get-Process 渡口助手 -ErrorAction SilentlyContinue
```

有的话：托盘右键退出，或 `taskkill /IM 渡口助手.exe /F`（**先点「停止并恢复直连」**，
否则系统代理会指着已关闭的端口）。

### B2. 装完打开显示「未激活」+「配置里没有门户地址」

说明读不到 `config.json`。检查：

```powershell
Get-Content "$env:LOCALAPPDATA\Ferry\config.json" -Raw
```

- 文件存在且有 `"token"` → 是**从别处启动的 exe**（比如从桌面单独拷出来的）。
  0.9.8 起会自动回退到安装目录的配置；更早的版本请直接启动
  `%LOCALAPPDATA%\Ferry\渡口助手.exe`
- 文件不存在 → 装错了目录，或者被清理软件删了。重装一次要回密钥

> `config.json` 里是激活令牌，丢了就要找管理员要新密钥。
> 0.9.8 起每次保存都会写 `config.json.bak`，主文件坏了会自动读备份。

### B3. 安装报错

| 错误 | 原因 | 处理 |
|---|---|---|
| `DeleteFile 失败；错误代码 5。拒绝访问` | 旧版（0.9.2 及以前）客户端是**管理员进程**，普通安装器杀不掉 | 托盘右键退出后再装；或右键安装包 →「以管理员身份运行」 |
| `CreateProcess 失败；错误代码 740` | 已提权的安装器在启动要求管理员的 exe | 0.9.6 起客户端是 `asInvoker`，不会再出现 |
| `Windows 已保护你的电脑` | SmartScreen 拦未签名 exe | 用下载页的「⚡ 一键安装」（脚本下载不打 MOTW）；或「更多信息 → 仍要运行」 |

> 错误 5 是**一次性迁移问题**：0.9.6 起客户端是普通权限，普通安装器能正常关掉它。

## C. 自动更新

### C1. 点了「更新」什么都没发生

   Get-ChildItem $env:TEMP -Filter 'Ferry-Setup-*.exe' | Select Name,Length,LastWriteTime

## D. 全局模式（TUN）

### D1. 按钮点了提示需要管理员

这是**设计如此**：TUN 要建虚拟网卡，必须管理员。点「开启」→ 确认 → 程序会退出并
自动以管理员身份重启（UAC 设为「从不通知」的机器不会弹框，看起来就是「闪一下」）。

重启后状态行应显示「全局模式 已开启」。

### D2. 重启后仍显示「待管理员授权」

说明提权没成功。确认：

```powershell
# 客户端进程是不是管理员？（看它有没有建出 FerryTun 网卡最直观）
Get-NetAdapter -Name 'FerryTun' -ErrorAction SilentlyContinue
```

- 网卡在 → 提权成功、TUN 起来了
- 网卡不在 → 看 `assistant.log` 里的 `[TUN]` 行；常见是 `wintun.dll` 缺失或
  mihomo 启动失败

### D3. 开了全局模式但系统图标显示「无 Internet」

**这是已知的副作用**（见 `docs/踩坑记录.md` 与 README 的限制）：TUN 期间客户端会把
Windows 的 NCSI 主动探测关掉（`EnableActiveProbing=0`），原值存在 `ncsi.bak`，
停止 TUN 时恢复。目的是避免「实际能上网、系统到处报断网」。

想恢复系统提示：先关闭全局模式，再删 `%LOCALAPPDATA%\Ferry\ncsi.bak` 并重启客户端。

### D4. 游戏/QUIC 还是不走

1. 确认状态行是「已开启」而不是「待管理员」
2. 看 `tun-config.yaml` 里的 `rules` 是否被改过
3. 有些游戏用自带的反作弊/虚拟网卡检测，会主动绕过 TUN——这类没有通用解法

## E. 门户

### E1. 网页打不开

```powershell
# 服务在不在
curl.exe --noproxy '*' --max-time 8 -o NUL -w "%{http_code}`n" http://10.13.24.1:8080/
# 进程在不在
ssh pcs "Get-Process python | Select Id,StartTime"
# 计划任务
ssh pcs "schtasks /Query /TN FerryPortal /FO LIST"
```

打不开但进程在 → 防火墙没放行 8080。

### E2. 管理面板进不去 / 密码忘了

密码在出口机的 `C:\ferry-portal\portal-admin.txt`。删掉这个文件重启服务会重新生成。

连续输错会锁定 15 分钟（`/admin/unlock` 页面可以解除）。

### E3. 「意见反馈」一直加载中

0.9.13 起已修（前端 JS 有个函数名笔误）。如果还出现：

- 打开浏览器控制台看有没有 `ReferenceError`
- 或直接查接口：登录后访问 `/api/admin/feedback`，应返回 `{"ok":true,...}`

## F. 激活与密钥

| 提示 | 原因 | 处理 |
|---|---|---|
| 密钥无效 | 输错 / 已被使用 / 已过期 | 面板里看「临时密钥」列表的状态；过期就重新生成 |
| 授权已到期 | `expiresAt` 到了 | 管理员续期 |
| 账号已停用 | 被管理员 `disable` | 面板里「启用」 |
| 换了台机器要重新激活 | 密钥绑定激活时的局域网 IP | 找管理员要新密钥 |

服务端权威状态在 `portal.db` 的 `sessions` 表（按 IP + token）。

## G. 出问题时抓什么给我

一条命令打包现场（在出问题的机器上跑）：

```powershell
$d = "$env:LOCALAPPDATA\Ferry"
$out = "$env:TEMP\ferry-diag-$env:COMPUTERNAME.txt"
@(
  "== version ==",
  (Get-Item "$d\渡口助手.exe").VersionInfo.FileVersion,
  "== os ==",
  [Environment]::OSVersion.VersionString,
  "== dpi ==",
  (Get-ItemProperty 'HKCU:\Control Panel\Desktop\WindowMetrics' -Name AppliedDPI -EA SilentlyContinue).AppliedDPI,
  "== config ==",
  (Get-Content "$d\config.json" -Raw -EA SilentlyContinue),
  "== proxy ==",
  (Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings' |
     Select ProxyEnable,ProxyServer | Out-String),
  "== adapters ==",
  (Get-NetAdapter | Select Name,Status | Out-String),
  "== log ==",
  (Get-Content "$d\assistant.log" -Tail 80 -EA SilentlyContinue)
) | Set-Content $out -Encoding UTF8
Write-Host "已生成 $out"
```

> `config.json` 里含 token，发给别人之前先把它删掉。
